# Student Management CRUD

A simple Student Management System built using Node.js, Express.js, EJS, MongoDB and Mongoose.

This project demonstrates CRUD operations for managing student records using MongoDB.

## Features

- Add new student
- View all students
- Edit student details
- Delete student
- MongoDB database integration
- Mongoose for database operations
- EJS templates
- Express.js routing
- Method Override for PUT and DELETE requests
- Form validation using Mongoose
- Environment variables using dotenv
- Simple responsive CSS design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MongoDB
- Mongoose
- Method Override
- Dotenv

## Student Details

- Name
- Roll Number
- Branch
- Semester
- Email
- Phone
- Gender
- Address

## CRUD Operations

### Create

Add a new student to the MongoDB database.

### Read

View all registered students.

### Update

Edit existing student information.

### Delete

Delete a student from the database.
